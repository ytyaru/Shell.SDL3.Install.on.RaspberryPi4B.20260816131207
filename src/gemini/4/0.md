ラズパイ4B(4GB)でSDL3の最新安定版のソースコードをZIP展開しソースコードからビルドしてインストールする全自動bashスクリプトを書きダウンロードできる形で提供しろ。

コードは単一責任の原則に従い共通化しろ。もしbashで難しそうならPythonファイルスクリプトを書きダウンロードできる形で提供しろ。

SDL3はIMEによる日本語入力ができ、指定したフォントで日本語表示でき、PNG画像やMP3が再生でき、ネット接続できること。

最新安定版は実行時に毎回GitHubからバージョン値を取得しろ。取得に失敗したらエラーを吐いて終了しろ。理由はソースコードの実装が間違っているため中断しコード修正すべきだから。

ソースコードやビルド成果物が既存なら済んでいる分のダウンロードや展開やビルドやインストールは飛ばせるようにしろ。作業場所のルートは`/tmp/`を使え。作業データは削除せず取っておけ。理由は失敗時に最初からやり直したくないから。メッセージやコメントは日本語を使え。

ビルドは2コアを使って高速実行できるようにしろ。

対象リポジトリのURLは以下。

https://github.com/libsdl-org/SDL
https://github.com/libsdl-org/SDL_image
https://github.com/libsdl-org/SDL_ttf
https://github.com/libsdl-org/SDL_mixer
https://github.com/libsdl-org/SDL_net

GeminiはURLの作成がドメインで終わってしまい破綻してしまうため工夫しろ。それはバージョン値を取得するURLでも同じだ。

例えば以下のように。

```sh
get_latest_version_url() {echo ""}
make_repo_url() {
    local base="https://github.com"
    local user="libsdl-org"
    echo "${base}/${user}/$1"
}
make_url "SDL"
make_url "SDL_image"
make_url "SDL_ttf"
make_url "SDL_mixer"
make_url "SDL_net"
```

全自動スクリプトは`sdl.sh`ファイルで提示しろ。尚、`sdl.sh install`/`sdl.sh uninstall`のサブコマンドでそれぞれインストールとアンインストールができるようにしろ。バージョン表示とヘルプも表示できるようにしろ。それ以外のコマンドはヘルプを表示しろ。

```sh
$ sdl.sh
SDLの最新安定版をインストールする。
GitHubにあるZipからソースコードをダウンロードしてビルドしインストールする。
ラズパイ4B(4GB)で動作させることを想定している。
  install    インストールする。
  uninstall  アンインストールする。
  version    バージョンを表示する。
  help       ヘルプを表示する。
```

バージョン表示。このバージョンは現在インストールされているバージョン値であること。

```sh
$ sdl.sh version
3.4.14
$ sdl.sh version image
3.4.4
$ sdl.sh version mixer
3.2.4
$ sdl.sh version net
3.2.0
$ sdl.sh version ttf
3.2.2
$ sdl.sh version all
sdl	3.4.14
image	3.4.4
mixer	3.2.4
net	3.2.0
ttf	3.2.2
```

コンパイラでは以下のように利用できるようにしろ。

```sh
g++ test_sdl3_full.cpp -o test_sdl3_full $(pkg-config --cflags --libs sdl3 sdl3-image sdl3-ttf sdl3-mixer sdl3-net)
```

SDL3のインストールが完了したら各APIが使えることを確認するためのソースコードとそれをビルドするためのbashスクリプトファイルを`/tmp/`のテストプロジェクトとして出力し、ビルド、実行しろ。

確認項目は、SDL3がIMEによる日本語入力でき、指定したフォントで日本語表示でき、PNG画像やMP3が再生でき、ネット接続できること。
