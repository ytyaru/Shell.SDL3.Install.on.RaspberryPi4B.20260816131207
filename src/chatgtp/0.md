# 質問

ラズパイ4B(4GB)にて最新安定版のSDL3のソースコードをGitHubからダウンロードし、ビルドし、aptで管理できるようcheckinstallを使ってインストールする全自動bashを書け。これにてバージョン管理も含めて日時が経過してからも全自動化できるはずだ。尚、拡張ライブラリを含めて全部含めること。メッセージやコメントは日本語で書け。
`g++ test_japanese.cpp -o test_sdl3 $(pkg-config --cflags --libs sdl3 sdl3-ttf)`のようにして常に最新版をビルドできること。
